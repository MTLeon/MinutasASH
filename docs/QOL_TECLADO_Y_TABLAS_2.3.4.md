# Productividad y atajos — Minutas ASH 2.3.4

## Atajos generales

| Atajo | Acción |
|---|---|
| Ctrl+N | Crear una minuta |
| Ctrl+O | Abrir una fuente |
| Ctrl+S | Guardar un borrador recuperable |
| Ctrl+Shift+S | Generar el documento Word |
| Ctrl+Shift+V | Pegar conversación o notas |
| Ctrl+Enter | Continuar con la acción principal de la etapa |
| F5 | Procesar la reunión |
| Ctrl+, | Abrir Preferencias |
| F1 | Abrir ayuda |

## Tablas

- Pulse un encabezado para ordenar; púlselo nuevamente para invertir el orden.
- Use Ctrl+A para seleccionar todas las filas visibles.
- Use Shift+clic, Ctrl+clic o arrastre vertical para seleccionar un rango.
- Use Ctrl+C para copiar encabezados y filas en formato tabulado.
- Use Esc para limpiar la selección.
- El menú contextual conserva las acciones disponibles mediante teclado.

## Revisión

| Atajo | Acción |
|---|---|
| Enter o Espacio | Aprobar la selección |
| F2 o doble clic | Corregir un punto |
| Supr | Eliminar puntos con recuperación mediante Deshacer |
| Ctrl+D | Descartar la selección |
| Ctrl+Z | Deshacer la última acción de revisión |
| Ctrl+F | Enfocar la búsqueda |
| Flechas | Recorrer las filas |

Al abrir o filtrar la revisión se enfoca automáticamente el primer punto visible y se muestra su evidencia. Las filas que requieren atención usan texto de alto contraste.

## Participantes e historial

- Participantes admite selección múltiple, edición con Enter/F2 y eliminación con Supr.
- Los rótulos “Notas de reunión”, “Transcripción” y “Hablante no identificado” no se agregan como personas.
- Historial incorpora búsqueda instantánea sin depender de mayúsculas o tildes.
- Enter carga la minuta, Supr la mueve a la papelera recuperable y F5 actualiza la lista.
- En la papelera, Supr solicita confirmación antes de eliminar definitivamente.

## Validaciones preventivas

Los códigos provisionales como 0, N/A o “sin proyecto” no pueden avanzar a procesamiento ni emisión. Esto evita generar números de minuta y carpetas definitivas con identificadores de relleno.
