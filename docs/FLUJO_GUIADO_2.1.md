# Flujo guiado 2.1

## Paso 1 — Reunión

Seleccione el VTT, cargue o escriba el proyecto y confirme los datos corporativos. El botón Sugerir construye el número con el formato:

```text
PROYECTO-MRE-PR-00
```

## Paso 2 — Participantes

La aplicación detecta hablantes y completa los datos disponibles desde el catálogo. Los participantes guardados se asocian al perfil del proyecto.

## Paso 3 — Revisión

Cada fila posee:

- Estado: pendiente, aprobado o descartado.
- Calidad: verde, amarillo o rojo.
- Categoría, responsable, plazo y referencia.
- Contexto original del VTT.

El documento no se emite mientras existan puntos pendientes cuando la aprobación obligatoria está habilitada.

## Paso 4 — Emisión

Se verifica transcripción, ficha, participantes, puntos, aprobación y cobertura antes de habilitar la generación Word.
