# Validación de release Minutas ASH 2.3.16

## Alcance

- Protección del archivo multimedia fuente durante la preparación y transcripción.

## Evidencia requerida

1. Una fuente original permanece disponible después de crear la copia de voz.
2. Una solicitud heredada con eliminación activada no borra la fuente.
3. La interfaz no ofrece eliminación de la fuente original.
4. La suite de calidad y la firma del instalador deben aprobar.
