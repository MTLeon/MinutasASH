# Hoja de ruta — Minutas ASH

## 2.1.x — piloto y estabilización

- Pruebas con reuniones reales de distintos tipos.
- Correcciones de experiencia de usuario.
- Ajustes del semáforo y la revisión guiada.
- Publicación del repositorio privado y primera release.
- Validación del actualizador con una versión 2.1.1.

## 2.2.0 — gestión de compromisos

- Panel de compromisos pendientes, vencidos y completados.
- Estados, observaciones y filtros por proyecto.
- Exportación controlada y recordatorios.
- Políticas de retención de fuentes y evidencias.

## 2.3.0 — integración Microsoft 365

- Bandeja de reuniones disponibles.
- Obtención controlada de transcripciones mediante Microsoft Graph.
- Publicación opcional en SharePoint o Teams.
- Autenticación corporativa y permisos administrados.

## 2.4.0 — plataforma documental ampliada

- Primer proveedor adicional para protocolos de aceptación.
- Plantillas PLC, HMI y tableros eléctricos.
- Formularios y validadores específicos por tipo documental.

## 3.0.0 — operación centralizada

- Repositorio SQL Server opcional.
- Usuarios, roles y auditoría centralizada.
- Catálogos compartidos.
- Flujo multiusuario y sincronización con trabajo local.
