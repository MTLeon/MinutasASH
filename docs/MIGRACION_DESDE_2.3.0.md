# Migración desde Minutas ASH 2.3.0 a 2.3.1

1. Cierre la aplicación.
2. Cree un respaldo desde 2.3.0 cuando sea posible.
3. Ejecute `MinutasASH_Setup_2.3.1_Online.exe`.
4. Abra la aplicación.
5. Verifique historial, proyectos, contactos y plantillas.
6. Confirme que el esquema informado sea 6.
7. Marque como prueba los ensayos anteriores que no deben participar en indicadores.

La migración agrega columnas y tablas; no elimina registros existentes. Antes de cambiar la base se genera una copia de seguridad.
