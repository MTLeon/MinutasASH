# Entradas flexibles, historial seguro y aprendizaje — 2.3.1

## Alcance

La versión admite VTT, TXT, DOCX, texto pegado y notas manuales sobre un único pipeline. Agrega papelera reversible, registros de prueba, correcciones estructuradas y diccionario técnico.

## Principios

- VTT sigue siendo la fuente preferida.
- La calidad de fuente determina la intensidad de revisión.
- Eliminar normalmente significa mover a papelera.
- Los ensayos se marcan como prueba.
- Aprendizaje significa registrar ejemplos aprobados, no reentrenar automáticamente.
- El diccionario solo normaliza vocabulario.
