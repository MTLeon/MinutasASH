# ADR-0001: repositorio privado

## Estado

Aceptada.

## Contexto

El código contiene lógica corporativa, recursos gráficos y una plantilla documental de uso interno.

## Decisión

Mantener el proyecto en un repositorio privado bajo control de ASH. No almacenar datos reales de reuniones ni certificados de firma.

## Consecuencias

- El acceso debe administrarse por equipo o colaborador.
- Los releases e instaladores serán privados.
- La documentación puede describir el sistema sin exponer datos de clientes.
