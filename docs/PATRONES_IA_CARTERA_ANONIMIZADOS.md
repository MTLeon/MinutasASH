# Patrones anonimizados para reuniones de cartera

Casos sintéticos derivados de estructuras lingüísticas observadas, sin transcripciones, nombres ni códigos reales.

## Primera persona

- “Lo voy a revisar hoy.” → compromiso; responsable: hablante.
- “Le voy a consultar a administración.” → compromiso; responsable: hablante.
- “Tengo que ingresarlo al sistema.” → compromiso; responsable: hablante.

## Acciones colectivas

- “Tenemos que coordinar la visita.” → compromiso colectivo; confirmar responsable.
- “Hay que volver a contactar al cliente.” → compromiso; responsable no inferido si no es explícito.

## Dependencias

- “Estamos a la espera de la orden.” → pendiente.
- “Dependemos de la confirmación del cliente.” → pendiente/dependencia.
- “Todavía no llega el pago.” → pendiente comercial.

## Condicionales

- “Si la próxima semana no hay respuesta, entonces cerramos técnicamente y notificamos.” → registrar condición y acciones, sin afirmar que ya ocurrieron.

## Contexto multiproyecto

- El último código válido se mantiene hasta que se menciona otro.
- Fechas, montos y años no deben convertirse automáticamente en códigos.
- Cada fila debe conservar proyecto y evidencia temporal.
