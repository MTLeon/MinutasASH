# Validación de release Minutas ASH 2.3.15

## Alcance

- Reclasificación de compromisos narrativos sin responsable o acción asignada.
- Detección local de continuidad para acciones repetidas entre minutas de un proyecto.

## Evidencia requerida

1. Un estado futuro no asignado se conserva como informativo.
2. Una acción similar a una minuta aprobada previa queda pendiente con una nota de continuidad.
3. La revisión por excepciones no aprueba automáticamente un punto marcado por continuidad.
4. La suite de calidad y la firma del instalador deben aprobar.
