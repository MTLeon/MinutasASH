# Notas de versión — Minutas ASH 2.3.1

## Objetivo

Entrega de estabilización centrada en entradas flexibles, limpieza segura del historial, reuniones de cartera y aprendizaje supervisado local.

## Añadido

- Fuentes VTT, TXT, DOCX, conversación pegada y notas manuales.
- Tipo de reunión “Revisión de cartera / jefes de proyecto”.
- Código de proyecto por punto.
- Datos bloqueantes visibles en la vista esencial, incluido “Minuta tomada por”.
- Papelera reversible, restauración y purga protegida.
- Registros de prueba excluidos del panel, numeración y aprendizaje.
- Limpieza asistida de intentos incompletos.
- Eventos de corrección y muestras aprobadas.
- Diccionario técnico por proyecto incorporado como vocabulario del prompt.
- Centro de aprendizaje en Administración.
- Manuales 2.3.1 integrados mediante F1.

## Mejorado

- Patrones coloquiales de compromiso y dependencia.
- Contexto persistente de código en reuniones multiproyecto.
- Revisión y Word con identificación de proyecto.
- Mensajes de fuente y calidad.
- Cierre explícito de libros XLSX en Windows.
- Seguridad de eliminación física.

## Compatibilidad

- Actualización desde 2.3.0.
- Esquema SQLite 6.
- SQLite sigue siendo el repositorio productivo.
- SQL Server permanece preparado, no habilitado.

## Limitaciones

- El aprendizaje no reentrena automáticamente el modelo.
- Audio/video y Microsoft Graph quedan fuera de esta entrega.
- Las fuentes manuales pueden carecer de marcas temporales reales.
