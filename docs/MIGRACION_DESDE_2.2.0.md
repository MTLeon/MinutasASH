# Migración desde Minutas ASH 2.2.0

1. Cierre la aplicación.
2. Cree un respaldo desde la versión anterior cuando sea posible.
3. Ejecute `MinutasASH_Setup_2.3.0_Online.exe`.
4. Instale sobre la ubicación existente.
5. Al iniciar, la base se respalda y migra del esquema 4 al 5.
6. Verifique historial, proyectos, contactos y configuración.
7. Abra Administración y genere un respaldo 2.3.0.

La actualización conserva modelos, runtime, documentos, historial y preferencias. El formato integrado continúa disponible aunque no se instalen plantillas administradas.
