Flujo: Reunión → Participantes → Revisión → Emitir.

Revisión rápida

Arrastre filas para seleccionar varias. Use Supr para descartar, Ctrl+A para seleccionar visibles y Ctrl+Z para deshacer.

Procesamiento

Use el perfil Automático. La aplicación mide la memoria antes y después de cargar el modelo, conserva checkpoints y libera el modelo al finalizar.
