Minutas ASH 2.3.0

Herramienta para preparar, revisar y emitir minutas corporativas desde transcripciones VTT de Microsoft Teams.

Flujo esencial

  1. Cree una nueva minuta.
  2. Seleccione o arrastre el VTT.
  3. Elija el proyecto, tipo de reunión y formato documental.
  4. Confirme participantes.
  5. Procese la transcripción.
  6. Apruebe, corrija o descarte cada punto.
  7. Revise el checklist y genere el Word.

Novedades 2.3.0

  • Catálogos de contactos, organizaciones, clientes y proyectos.
  • Plantillas Word cargables, versionadas y validables.
  • Importación y exportación CSV/XLSX.
  • Respaldo/restauración y auditoría local.
  • Centro de ayuda integrado con manual maestro.

Ayuda dentro de la aplicación

Presione F1 o use Ayuda → Centro de ayuda. Allí encontrará el manual maestro, el manual de usuario, el manual de configuración y la guía del programador.

Importante: la aplicación prepara un borrador. Revise el contenido antes de distribuirlo a un cliente.
