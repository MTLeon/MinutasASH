# Notas de versión Minutas ASH 2.3.17

## Destilación de conocimiento local

- Administración incluye Preparar ejemplo oro en la sección Aprendizaje.
- El flujo toma una transcripción y una minuta DOCX final validada, extrae la matriz de acuerdos y genera un JSONL para revisión.
- Los ejemplos se etiquetan con proyecto y cliente para evitar mezcla de conocimiento entre contratos.
- La exportación no ajusta el modelo ni envía datos fuera del equipo. Un ajuste LoRA requiere revisar y acumular un conjunto suficiente de ejemplos oro.
