# Prueba piloto Windows 11 — Minutas ASH 2.1.0

## Instalación

1. Verificar SHA-256.
2. Instalar como usuario normal.
3. Completar preparación inicial.
4. Confirmar acceso directo y menú Inicio.

## Flujo funcional

1. Crear nueva minuta.
2. Seleccionar `entrada/reunion_prueba_ejemplo.vtt`.
3. Crear o cargar un proyecto.
4. Usar Sugerir número.
5. Confirmar participantes.
6. Procesar.
7. Revisar el contexto de cada punto.
8. Aprobar o corregir todas las filas.
9. Validar emisión.
10. Generar Word.

## Persistencia

- Cerrar y abrir la aplicación.
- Confirmar historial, proyecto y participantes.
- Procesar nuevamente el mismo VTT y verificar la advertencia de duplicado.

## Personalización

- Probar tema claro y oscuro.
- Cambiar color, fuente, escala y densidad.
- Confirmar persistencia después de reiniciar.

## Evidencias para soporte

- Diagnóstico generado.
- `MinutasASH.log`.
- Capturas de pantalla.
- Word resultante.
