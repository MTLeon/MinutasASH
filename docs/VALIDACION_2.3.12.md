# Validación de release Minutas ASH 2.3.12

## Alcance

- Unión local rápida y control de cobertura eficiente para transcripciones extensas.

## Validaciones requeridas

1. El perfil local rápido debe conservar todos los ítems de los bloques sin solicitar consolidación al modelo.
2. Las reuniones breves deben conservar la comprobación semántica focalizada.
3. La suite de calidad debe aprobar formato, lint, tipos, pruebas y cobertura.
4. Los instaladores deben tener firma Authenticode válida y completar sus smokes aislados.
