# GitHub — siguiente etapa

Después de aprobar la versión 2.2.0:

1. Crear un repositorio privado `minutas-ash`.
2. Publicar el código como tag `v2.2.0`.
3. Proteger `main`.
4. Activar GitHub Actions.
5. Publicar el instalador y SHA-256 en GitHub Releases.
6. Configurar `github_owner` y `github_repo` en Minutas ASH.
7. Crear una versión 2.1.1 de prueba para validar el actualizador.

No se almacenarán tokens de GitHub en el ejecutable.
