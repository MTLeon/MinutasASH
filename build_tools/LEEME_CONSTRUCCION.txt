CONSTRUCCIÓN DEL INSTALADOR FINAL

Este contenido es para el computador de desarrollo, no para los usuarios finales.

1. Descomprima el proyecto en una ruta corta, por ejemplo:
   C:\ASH\MinutasASH_v5

2. Ejecute:
   CONSTRUIR_INSTALADOR_FINAL.bat

3. Al terminar, distribuya únicamente:
   dist_installer\MinutasASH_Setup_<VERSION>_Online.exe
   dist_installer\MinutasASH_Whisper_CPU_<VERSION>.exe

El usuario final no necesita Python, pip, archivos BAT ni acceso al código fuente.
Durante la instalación se descarga el componente local oficial y se prepara el
perfil de procesamiento requerido.
