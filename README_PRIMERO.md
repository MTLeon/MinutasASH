# ENTREGA DE PRUEBA — MINUTAS ASH 2.3.3

1. Descomprima el paquete en una carpeta nueva y corta.
2. Ejecute `CONSTRUIR_INSTALADOR_FINAL.bat` como usuario normal.
3. Instale `dist_installer\MinutasASH_Setup_2.3.3_Online.exe`.
4. Mantenga el perfil de procesamiento en **Automático**.
5. Procese una reunión corta y luego una reunión extensa.
6. Cancele una prueba después de completar un bloque y compruebe la reanudación.
7. Revise `docs\PRUEBA_PILOTO_WINDOWS11_2.3.3.md`.

El instalador final debe construirse en Windows. Los datos persistentes no están dentro de la carpeta del programa.
