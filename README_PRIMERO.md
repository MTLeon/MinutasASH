# ENTREGA DE PRUEBA — MINUTAS ASH 2.1.0

1. Descomprima el paquete en una carpeta nueva y corta, por ejemplo:

```text
C:\ASH\MinutasASH_2_1
```

2. Ejecute como usuario normal:

```text
CONSTRUIR_INSTALADOR_FINAL.bat
```

3. Distribuya únicamente:

```text
dist_installer\MinutasASH_Setup_2.1.0_Online.exe
dist_installer\MinutasASH_Setup_2.1.0_Online_SHA256.txt
```

4. En el equipo piloto, pruebe el flujo completo y conserve el diagnóstico generado desde Configuración.

La línea 2.x reemplaza la numeración histórica 5.x. El cambio es intencional y está documentado en `docs/decisiones/0003-reinicio-linea-versiones.md`.
